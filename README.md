# Text Transposer

This is a zig program that takes in a text file and transforms the text casing. It's a learning project.

## Roadmap

### 1.0

- Transform UTF-8 latin characters only
- Transform lowercase letters to upper case
- Transform uppercase letters to lower case

### 1.1

- Transform UTF-8 numbers in the following scheme:
  - 0 <-> 9
  - 1 <-> 8
  - 2 <-> 7
  - 3 <-> 6
  - 4 <-> 5

### 1.2

- Add support for accented latin characters
